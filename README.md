# Aorta-StarCCM-Simulations
A computational fluid dynamics (CFD) study comparing blood flow behavior in a simulated aorta model against real-life physiological flow data. Built and solved in Siemens STAR-CCM+, the simulation models the geometry, flow velocity, and pressure distribution through the aortic arch to evaluate how closely CFD predictions align with real-world cardiovascular flow patterns.
